MITESH CHANDEL PORTFOLIO
========================

FILES
- index.html: page structure and content
- style.css: layout, responsive design, light/dark themes, animations
- script.js: theme toggle, mobile navigation, project filters, copy-email, scroll progress

RUN
1. Extract the folder.
2. Open index.html in a browser. No build step is required.
3. For best results, use VS Code and the Live Server extension (optional).

BEFORE PUBLISHING
- Add your actual resume PDF at assets/resume.pdf.
- Check all project links. Some project cards currently link to your GitHub profile because exact repository URLs for every project were not confirmed.
- Update any project descriptions so they match the current state of each repository.
- Google Fonts is optional; if offline, the page falls back to system fonts.
- Deploy using GitHub Pages, Netlify, or another static hosting service.
